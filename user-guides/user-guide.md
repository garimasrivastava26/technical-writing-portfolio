## Introduction

MyTask is a simple desktop-based application designed for the Windows operating system. 
It allows users to create, edit, delete and mark tasks as complete. 
The application also provides an option to set a category for a task. Category options include Personal, Work, and Shopping.
The application has an option to set the due date for a task.
Both category and due date are optional fields and can be changed any number of times.
The application includes a search feature that enables users to search for tasks by task name.

## Intended Audience

The MyTask application is suitable for a wide range of users. The intended audience includes regular home users, students, working professionals, shop owners, or anyone who wants to organize their daily tasks.

## Getting Started

### Launch MyTask

Follow these steps to launch MyTask:
1. Double-click the **MyTask** icon to open the application.
2. The MyTask dashboard appears.

### Overview of the Main Window

The MyTask dashboard contains the following options:

1. **New Task** button
2. **Search** bar
3. **Category** filter
4. **Task** list


## Managing Tasks

### Create a Task

Follow these steps to create a task:

1. Click  **New Task**.
2. Enter the task name.
3. Optionally, choose a due date.
4. Optionally, select a category.
5. Click **Save**.

### Edit a Task

Follow these steps to edit a task:

1. Go to the **Search** bar.
2. Type the task name.
3. Press **Enter**.
4. Click the task in the search results.
5. Modify the desired task details, such as the task name, category, and due date.
6. Click **Save**.

### Delete a Task

Follow these steps to delete a task:

1. Go to the **Search** bar.
2. Type the task name.
3. Press **Enter**.
4. Click the task in the search results.
5. Click **Delete**.
6. Click **OK** to confirm the deletion.

### Mark a Task as Complete

Follow these steps to mark a task as complete:

1. Go to the **Search** bar.
2.  Type the task name.
3. Press **Enter**.
4. Click the task in the search results.
5. Select the **Completion date**.
6. Click ** Complete**.
7. Verify that the task status is displayed as **Completed** before exiting the application.

## Troubleshooting

|  Issue  |  Possible Solution  |
| -- | -- |
|  MyTask does not open  |  Restart the application. If the issue persists, restart your computer.  |
|  Unable to create a task  |  Verify that you entered a task name before clicking **Save**.  |
|  Unable to find a task  |  Check the spelling of the task name or clear the search box and try again.  | 
|  Changes are not saved |  Verify that you clicked **Save** before closing the task.  |  
|  Unable to mark a task as complete  |  Verify that you selected a **Completion date** and clicked **Complete**.  |

## Frequently Asked Questions (FAQs)

Find answers to common questions about using the MyTask application.


#### Q: Can I mark a task complete if no due date is assigned to it?
Yes. The due date is an optional field, so a task can still be marked as completed without it.
#### Q: Can I create a task without selecting a category?
Yes. It is an optional field that helps organize tasks. It can be assigned or changed later.
#### Q: Can I change the category later?
Yes. The category can be changed any number of times.
#### Q: Can I delete a completed task?
Yes. A task can be deleted at any time regardless of its status. However, it cannot be recovered once deleted.
#### Q: Can I edit a completed task?
Yes. If you need to correct or update task details after completion, you can edit the task and save your changes.
