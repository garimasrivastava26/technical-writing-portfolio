# MyTask Release Notes

**Version:** 1.1
**Release Date:** August 12, 2026

## What's New

- **New Search Feature:** Users can now find their tasks by entering the task name in the **Search** bar.

## Enhancements

- **Predefined Categories added:** Personal, Work, and Shopping have been added as predefined category options.
- **Edit Completed tasks:** Users can now edit completed tasks.

## Bug Fixes

- **Due Date Fix:** Fixed an issue where changes to a task's due date were sometimes not saved.
- **Completed Status Fix:** Fixed an issue where the application occasionally failed to display the **Completed** status immediately after a task was marked complete.

## Known Issues

- **Search Result Issue:** Search may not return the correct result when a task name contains the `#` symbol.
