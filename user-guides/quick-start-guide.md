# MyTask Quick Start Guide

## Purpose
This guide helps first-time users install and launch MyTask, create a task, and mark it as complete.

## Prerequisites

The user should have the following prerequisites before starting:
+  A Windows computer with an internet connection to download the installer.
+ Administrator rights to install the application.
+ Access to the MyTask installer.

## Installation

Follow these steps to install MyTask:

1. Download the MyTask installer.
2. Select the appropriate `.exe` file for your operating system (64-bit or 32-bit).
3. Open the downloads folder.
4. Double-click the downloaded installer.
5. Click **Yes**.
6. Verify the default destination folder for the installation.
7. The default installation path is  'C:\Program Files\MyTask\'.
8. To change the installation location, select a different folder.
9. Once the destination folder is set, click **Install**.
10. Verify that the message **Installation successful** is displayed.
11. Click **Close**.
12. Go to the Windows search bar and search  for **MyTask**.
13.  Open **MyTask** to verify that the installation completed successfully.

## Launch MyTask

Follow these steps to launch MyTask:

1. Double-click the **MyTask** icon to open the application.
2. The MyTask dashboard appears.

## Create Your First Task

Follow these steps to create your first task:

1. Click  **New Task**.
2. Enter the task name.
3. Optionally, choose a due date.
4. Click **Save**.

## Mark a Task as Complete

Follow these steps to mark a task as complete:

1. Go to the **Search** bar.
2. Type the task name.
3.  Press **Enter**.
4. Click the task in the search results.
5. Select the **Completion date**.
6. Click **Complete**.
7. Verify that the task status is displayed as **Completed** before exiting the application.
